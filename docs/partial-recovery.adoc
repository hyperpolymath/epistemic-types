= Partial recovery from the retained pair
:revdate: 2026-11-07

== Problem and exact contract

`EchoBridge.Recovery C` requires a total decoder on every visible/residue
pair, including pairs that no source produces. The optional canonical
adapter identifies that existing contract with Echo's `ExactRecovery`.
The new `EpistemicTypes.PartialRecovery` module adds a separate contract:

[source,agda]
----
decode    : B -> R -> Maybe A
roundtrip : (x : A) -> decode (observe x) (retain x) ≡ just x
----

The decoder receives only the visible value and residue. It receives no
source, certificate or inhabitant of a fibre. All carriers are `Set`; the
existing `Retention A B R`, including its arbitrary certificate family,
stays fixed. The new theorem does not infer recovery from certificate
validity and does not turn a standpoint into an access-control label.

`PartialRecovery` alone says nothing about successful decoding at an
unreachable pair. `SuccessSound rec` is the separate law that every
successful output reproduces the input pair. Keeping these laws separate
is necessary: converting an arbitrary total recovery to `just` preserves
the source round trip but can succeed on an unreachable input.

This is standard constructive mathematics about left inverses and
decidable images. The contribution is a checked API boundary and its
correspondence with the owning Echo definition, not a new fibre theorem,
a novel type primitive or a claim of minimum information cost.

== Constructive characterization

Write `pair x = (observe x, retain x)`. The module defines:

* `Image C y r = Σ A (λ x -> pair x ≡ (y , r))`, an ordinary
  proof-relevant fibre containing an actual source and an equality path.
* `Separates C`: equal retained pairs imply equal sources.
* `ImageDecision C`: for each pair, return either a concrete inhabitant of
  its fibre or a function refuting every inhabitant.

The following constructive maps prove both existence implications between
a partial recovery with `SuccessSound` and the pair of obligations
`Separates C` and `ImageDecision C`:

[cols="2,4",options="header"]
|===
|Declaration |Proved obligation
|`partialSeparates`
|Every partial recovery separates sources. The proof uses the decoder's
two round trips and injectivity of `just`.
|`soundPartialDecidesImage`
|Partial recovery plus success soundness decides the fibre: `just x`
supplies the source and matching path; `nothing` contradicts the round trip
of any proposed source witness.
|`fromImageDecision`
|Separation plus an explicit image decision constructs partial recovery.
A positive decision chooses a source internally; separation proves that
the chosen source equals the original on every generated pair.
|`imageDecisionSound`, `imageDecisionComplete`
|For this construction, successful output exactly corresponds to a
matching source. Completeness recovers every supplied inhabitant of the
fibre; soundness returns the matching equality for each successful output.
|===

These are existence constructions, not inverse equalities between records,
decision procedures or proof fields. No equality of all certificates or
equality paths, proof irrelevance, function extensionality, choice axiom,
propositional truncation or quotient is assumed. Image decidability does
not follow from separation, a certificate, or the name of the retention
contract. A concrete decision procedure is an explicit input.

The proof-relevant image is useful as a specification, but its projection
is not a decoder from the pair alone. Even a constant map on two sources
has witnesses containing either source. `witnessProjectionRoundtrip`
checks this trivial projection; `witnessProjectionDependsOnWitness` and
`noCollidingPartial` show why it cannot establish the pair-only contract.

== Totality and its boundary

`totalToPartial` wraps the existing total decoder in `just`.
`partialToTotal` fills failed outputs with a caller-supplied source
`fallback : A`. The source round trip ensures that the fallback is never
used on a generated pair. `totalPartialDecoder` proves that converting an
existing total decoder to partial and back preserves all its outputs,
pointwise, including off-image outputs.

The opposite composition may replace `nothing` with `just fallback`;
no two-sided isomorphism is claimed. A fallback is sufficient, not asserted
to be necessary for every possible carrier. In particular, an empty source
with inhabited visible/residue space admits an always-failing partial
recovery but no total recovery. This refutes unconditional totalization.

== Executable finite controls

`PartialRecoveryExamples.agda` checks the complete two-Boolean visible
space with source `Bool` and a singleton residue. Observation sends `b`
to `(b, false)`. An explicit image decision succeeds on the two generated
pairs and rejects the two unreachable pairs. The decoder and reconstructed
image decision reduce on both branches. Two fallback choices agree on all
generated pairs and differ off-image.

The same module also proves:

* Empty-source partial recovery exists while total recovery is impossible.
* Constant observation and residue on `Bool` forbid every partial recovery,
  even though every generated residue is certified and witness projection
  has a trivial round trip.
* A valid total decoder wrapped in `just` succeeds on an unreachable input
  whose returned source is incompatible with that input.

The expected-rejection gate includes `CollidingPartialRecovery` and
`PartialSuccessProvesImage`. They must reach their intended Boolean type
mismatch with Agda exit 42; a tool, import or parse failure does not count.
These finite controls supplement the generic proofs. They do not claim
runtime refinement or performance bounds.

== Canonical ownership and sibling boundaries

`tests/integration/CanonicalPartialRecovery.agda` imports the actual
`Echo.Echo` and identifies `Image C y r` with
`Echo (retainedPair C) (y , r)` by definitional equality. The two conversions
and their record-free inverse laws preserve the particular source and path.
`fromCanonicalDecision` uses a decision over that owning fibre. The existing
`RecoveryExamples` root executes its finite generated and unreachable cases.
Echo acquires no Epistemic dependency; the builtins-only core imports no
standard library or sibling module.
