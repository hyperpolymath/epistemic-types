== What it is (as we use it)

In this repository an *epistemic type* is a *standpoint-indexed modal type
former*

----
E : K -> Set ℓ -> Set ℓ
----

where `K` indexes epistemic standpoints (agents, observers, evidence states,
accessibility contexts, warrant regimes). The reading of `E κ A` is that `A` is
*epistemically available from standpoint `κ`*: known, believed, observed,
warranted, inferable, or assertable under that standpoint. This is the operative
definition as the code actually uses it, and it is the form named in
`README.adoc`. The current checker profile and receipt state live in
`PROOF-STATUS.adoc`; `AFFIRMATION.adoc` is a dated historical receipt.

The library's defining move is to *separate the interfaces* rather than ship one
omnibus modality (`src/EpistemicTypes/Base.agda`):

* `Modality` supplies only `E` and `map` — an indexed endofunctor family, no
  monad, no comonad, no `return`/`bind`/`extract` by default.
* `LawfulModality` adds the functor laws as explicit fields.
* `FactiveModality` adds `reflect : E κ A -> A` (the factivity / truth axiom).
* `BeliefModality` *intentionally has no* `reflect`.
* `ReturnModality` makes a strong introduction rule explicit only when wanted.

Warrant is treated as deliberately *non-factive but proof-relevant*
(`src/EpistemicTypes/Warrant.agda`). `Warrant K κ A` records a *type of
evidence tokens* `Evidence : Set wℓ` for a claim `A` and carries *no* field
`Evidence -> A`; `Epi K κ A` packages a warrant with one such token, and
holding `Epi K κ A` *still does not give you `A`*. Soundness is a *separate* interface,
`SoundWarrant`, which alone adds the map `sound : Evidence -> A` (exposed as
`sound-epi`). So an evidence token is an instrument of attestation, not a
licence to extract the proposition.

Standpoint accessibility is a *preorder* `κ ≤κ κ'`
(`src/EpistemicTypes/Access.agda`), read as "`κ'` is at least as informed as
`κ`"; transport (`increase`) moves epistemic availability up the order, and the
preorder and transport laws are fields because arbitrary standpoints do not
determine them.

`src/EpistemicTypes/ProofTransport.agda` applies the same discipline to
*proof transport across trust boundaries*. One artefact is read three ways — von
Neumann bytes, a Curry–Howard proof, an epistemic status relative to a holder —
via `View holder artifact status claim`. `transmit` moves *bytes, not
proofhood* (a sender's `Proof` arrives only as a `Receipt`); `verify` recovers
proofhood through a successful sound check of an explicit
`Meaning holder artifact claim`. `proofSound` derives that meaning;
`proofNeedsChecker` remains a weaker structural projection. Public transport
requires a proved implication between the holders' meanings. The earlier
token-only encoding did not establish semantic truth. All of the above is in the current 22-module source tree. The exact checker
profile and receipt status are recorded in `PROOF-STATUS.adoc`; the June counts
in `AFFIRMATION.adoc` are historical.

== The established structure it instantiates (and where it is from)

Honesty first, because it is load-bearing: epistemic-types' *single deep
mathematical identity* remains deliberately unsettled. The former Kripke gap is
closed: `src/EpistemicTypes/Kripke/` now implements
a world-indexed `Box`, constructive frame correspondences, a non-factive model,
a residual-candidate frame, and a dependence counterexample. The open question
is whether this scoped semantics, explicit-warrant reading, and map-only base
select one deeper placement or remain a useful assembly of established
structures. No monadic/comonadic variance verdict follows from the Kripke
milestone.

* *Epistemic logic.* The modal treatment of knowledge and belief as distinct
  operators, with belief deliberately lacking the truth (factivity) axiom that
  knowledge has — Jaakko Hintikka, _Knowledge and Belief: An Introduction to the
  Logic of the Two Notions_ (Cornell University Press, 1962). Our
  `FactiveModality` (with `reflect`) versus `BeliefModality` (without) is exactly
  this knowledge/belief split.

* *Kripke semantics / relational possible-worlds models.* Saul A. Kripke,
  "Semantical Considerations on Modal Logic," _Acta Philosophica Fennica_ 16
  (1963), pp. 83–94. The repository now has a realised, scoped relational
  semantics: `Frame`, world-indexed `Box`, T and 4 in both constructive
  directions, and the forward 5 and D maps. It is not a complete epistemic
  logic, and the converses of 5 and D are not claimed.

* *Justification logic / the Logic of Proofs* — the *standout* candidate.
  Sergei Artemov, "Explicit Provability and Constructive Semantics,"
  _The Bulletin of Symbolic Logic_ 7(1) (2001), pp. 1–36; and Sergei Artemov and
  Melvin Fitting, _Justification Logic: Reasoning with Reasons_ (Cambridge
  University Press, 2019). Justification logic replaces an opaque `□F` with
  explicit justification terms `t : F` ("`t` is evidence for `F`"), where
  `t : F` does *not* entail `F` unless a *separate factivity axiom* is assumed.
  That is precisely the shape of our non-factive `Warrant` (an evidence token
  that does not yield `A`) with `SoundWarrant` added as the separate factivity
  interface. We claim the *correspondence is suggestive*, not that we have built
  justification logic.

* *Standpoint logic.* Lucía Gómez Álvarez and Sebastian Rudolph,
  "Standpoint Logic: Multi-Perspective Knowledge Representation," in
  _Formal Ontology in Information Systems (FOIS 2021)_ (IOS Press, 2021). Our
  indexing of a modality by a standpoint `κ`, with an accessibility order between
  standpoints, sits in this family.

* *Indexed / graded modalities.* The broader literature on graded and indexed
  modal type formers (graded comonads / coeffects; e.g. the graded-modal
  literature around Katsumata, Orchard, and others) supplies the general shape of
  a `Set`-indexed modality with transport along an order; we cite it
  conservatively at the level of the field rather than pinning one paper.

The implemented Kripke set-out establishes one precise semantics but does not,
by itself, settle the object's positive identity. `Kripke.Residual` interprets
worlds as candidate readings constrained by observation and evidence;
`Kripke.Dependence` then proves that candidate sets alone do not determine
which assumptions a conclusion depends on. The deep-identity question remains
a hypothesis at exactly that broader level, not as a claim that no frame exists.

== What is ours, and what is not (the contribution boundary)

What is *borrowed* is the mathematics: the knowledge/belief modal split, the
relational accessibility idea, the explicit-evidence-without-factivity shape of
justification logic, the standpoint-indexing idea, and the graded/indexed-modality
machinery — all authored by others and cited above.

What is *ours* is the *modelling and assembly*: the specific Agda
*interface-separation* (`Modality` / `LawfulModality` / `FactiveModality` /
`BeliefModality` / `ReturnModality`; `Warrant` versus `SoundWarrant`), and the
*standpoint-indexed proof-transport* calculus that makes proofhood holder-relative
and proves semantic soundness relative to Meaning through `proofSound`. Its
usefulness is demonstrated by concrete, checkable artefacts in the source and
current proof ledger:

* the authoritative inventory is 22 source modules and 13 expected-rejection
  controls; `tests/check-policy.sh` enforces the complete strict pragma,
  standalone import boundary, zero escape hatches, and a generated
  `[SafeFlagPostulate]` negative control; the hosted profile receipt status is
  recorded in `PROOF-STATUS.adoc`;
* `Warrant.sound-epi` makes extraction `Evidence -> A` available *only* via the
  separate `SoundWarrant.sound` field — non-factivity by construction;
* `Examples.no-polymorphic-belief-reflection` and
  `no-polymorphic-epi-reflection` *refute* a generic
  `(A : Set) -> Belief rough A -> A` (resp. `Epi`) by exhibiting a belief/warrant
  for `⊥`;
* `ProofTransport.proofNeedsChecker` (structural projection; `proofSound` is the semantic guarantee), with
  `designatedBindsHolder`, `opaqueNotCertifying`, and `verifyReceiptIsGap` giving
  the explicitly qualified public portability / designated-bound / receipt-never-certifies distinction.

These results are used as source interfaces downstream. In particular,
choreographic-types imports the warrant interface and reports K-CUT-LOSS,
directional K-CUT-WARRANT bounds and transport, and asynchronous variants as
proved for its finite binary/plain-merge fragment. It does *not* close
payload/data-dependent warrant soundness, recursion, full merge, or every
asynchronous generalisation. Those are sibling results and limits, not local
proofs silently absorbed here.

[NOTE]
====
**On contribution (the same stance in every sibling repo).** We did not invent the
mathematics this work rests on. Graded monads, tropical / idempotent dioids, multiparty
session types and choreographies, and epistemic / justification logic are established
structures authored by others, cited above. What is ours is the *modelling*: we apply these
structures as instruments fitted to specific domains — verifiable WebAssembly, federated
identity, BEAM sandboxing, structured information loss — in places the established corpus had
not been instantiated this way, and we report only where the fit has already produced
*checkable artefacts*. The contribution is the model and its demonstrated usefulness, not the
underlying mathematics. This is deliberate, and it is a strength: a claim that concedes its own
foundations is survivable; one that claims invention dies at the first citation.
Echo-types' EI-2 integration-recipe investigation is now *closed negatively via
PATH B*: the recipe did not carry substantive simultaneous cross-axis content,
so the distinctness claim was narrowed and positive identity remains open. That
negative result is not an invitation to reopen EI-2 from this repository.
====

== Current sibling boundaries (documentary, not imported)

* *Echo Types*: EI-2 terminated negatively through PATH B and narrowed the
  integration-based distinctness claim. Positive identity remains open. The
  canonical Echo correspondence checked here is representation/lowering only.
* *Residual Evidence Types*: the repository is operated in production, while
  its own README still classifies the mathematical/API maturity as early
  research with no stable API. Its checked corpus has advanced through
  dependence-preserving composition, revision/retraction, and a certified
  finite checker/explorer correspondence. This repository proves one local
  mirror result and does not stabilise or absorb that API.
* *Secret Types*: the standalone repository owns confidentiality labels and
  proves generic termination-insensitive noninterference over its `Lattice`
  record/down-closed observers, with the two-point theorem as an instance.
  Termination-sensitive noninterference and declassification remain open. No
  `Secret` API or IFC theorem is added here; `docs/secret-types.adoc` is a
  boundary/history note.
* *Choreographic Types*: only the scoped K-CUT results described above are
  imported as documentary status. Universal K-CUT or global
  data-dependent-warrant soundness is not claimed.

== Is-not, and what is still open

To keep boundaries un-eroded:

* epistemic-types *is NOT a complete epistemic logic*. It now does implement a
  scoped constructive Kripke semantics, including worlds, accessibility, `Box`,
  exact frame-condition maps, and countermodels. It does not claim classical
  converse 5/D, completeness, decidability, or a runtime epistemic system.
* epistemic-types *is NOT factive by default*. Factivity (`reflect`,
  `SoundWarrant.sound`) is a *separate, assumed* interface; the default
  `Warrant`/`Belief` carry no truth axiom. A reader who treats a warrant as a
  proof of its claim has crossed exactly the line this repo draws.
* the epistemic modality, Echo retention, and resource bounds remain separate.
  `E κ (Echo C y)` describes availability of a certified residue;
  `BoundedEcho C measure budget y` adds a measure inequality. The optional
  canonical integration proves residue representation and lowering agreement.
  No full graded-comonad or physical-loss theorem follows from this bridge.
* epistemic-types *is NOT a verified external system*. The green typecheck
  checks the formalised types and propositions; it does not establish that any real
  attestation protocol, CRDT read path, or proof-carrying-code pipeline
  *refines* it. There is no production implementation in this repo.
* the `SurrealBridge` *is NOT* the full Conway proper class of surreals — only
  the finite `daySurrealAccess` birthday tower over `Nat` is inhabited.

*Honestly open*: a complete epistemic logic beyond the implemented frame
fragment; classical converse 5/D if desired; data-dependent warrant soundness;
law-bearing modality instances where laws are currently fields; a graded
comonad and full graded-loss logic; richer day-bounded surreal fragments; and
the variance verdict for any specific epistemic modality. The Kripke semantics
itself is no longer on that list. It remains too early to name one positive deep
identity, and no generic `bind` or `extract` is promised.
