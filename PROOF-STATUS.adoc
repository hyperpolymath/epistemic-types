This is the current, source-anchored verification record for the Agda
formalisation. The authoritative positive tree contains *22 source modules* and
the negative-control manifest contains *13 expected-rejection fixtures*. The
source is constructive, builtins-only, map-only at its base interface, and has
no postulates or proof escape hatches. Exact theorem scope and trust boundaries
are recorded below; historical snapshots remain in `AFFIRMATION.adoc` and are
not current inventory.

== Status vocabulary

This document uses the estate proof-policy vocabulary:

* `PROVEN` — accepted by the named kernel under its safe profile, with no proof
  escape hatch;
* `TESTED` — a bounded, sampled, integration, or expected-rejection control;
* `ASSUMED` — an explicit premise or an externally reported correspondence not
  rechecked by this repository;
* `OPEN` — not discharged.

The separate cross-prover labels `AGDA-PENDING`, `AGDA-VERIFIED`,
`COQ-CHECKED`, `LEAN-CHECKED`, `BRIDGE-PENDING`, and `RECONCILED` describe
verification legs; they do not strengthen the proof-policy status.

== Verification profile and current receipt

The policy entry point is `scripts/check.sh`. It runs:

[source,shell]
----
bash tests/check-policy.sh
bash tests/check-proofs.sh
bash tests/check-rejections.sh
----

Every first-party Agda entry point is invoked with the canonical theory profile
`--safe --without-K --cubical-compatible`; source files additionally declare
`--exact-split --no-sized-types --no-guardedness`. Positive source checks use
`--no-libraries --double-check --ignore-interfaces -W error`. The policy gate
also inventories all 22 source modules and 13 rejection fixtures, rejects proof
escape hatches and non-core imports, and verifies a generated negative control:
`--safe` must reject a planted postulate with Agda's expected diagnostic and
exit code.

The most recent hosted receipt before adoption of the explicit
`--cubical-compatible` CLI requirement is Proof Safety run
https://github.com/hyperpolymath/epistemic-types/actions/runs/40445723481[40445723481]
at source commit `5422cd5bf1418c44321bf0f77e894737a451d8f5` (Agda 2.6.4.3), where both
`Proof core and rejection controls` and `Canonical Echo correspondence` passed.
Because that command did not spell out the new CLI flag, it is retained as
historical evidence, not as the receipt for the 2026-11-01 profile.

Current profile status at the time of this edit: `AGDA-PENDING`. A successful
hosted run of the command above is required before labelling this revision
Mathesis Grade 3. No missing tool, import failure, or unexpected rejection is a

== External pinned evidence, not local closure

Choreographic-types reports machine-checked K-CUT results for its explicitly
finite, binary-choice, plain-merge fragment, including K-CUT-LOSS, the
directional K-CUT-WARRANT bound, transport, and asynchronous variants. It also
reports `SoundWarrant` for warrants determined by that type-level frame.
Data-dependent warrants, recursion, full merge, and the wider asynchronous
forms remain open there. The previously recorded pinned E-6 receipt remains
external evidence; this repository does not generalise it into global warrant
soundness and does not count it as a locally rechecked theorem.

The current cross-repository status statements in
`docs/what-epistemic-is.adoc` are documentary pointers. They are not imports,
build dependencies, or independent proof legs for this repository.
