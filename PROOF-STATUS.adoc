This document uses the estate proof-policy vocabulary:

* `PROVEN` — accepted by the named kernel under its safe profile, with no proof
  escape hatch;
* `TESTED` — a bounded, sampled, integration, or expected-rejection control;
* `ASSUMED` — an explicit premise or an externally reported correspondence not
  rechecked by this repository;

== Verification profile and current receipt

The policy entry point is `scripts/check.sh`. It runs:

[source,shell]
----
bash tests/check-policy.sh
bash tests/check-proofs.sh
bash tests/check-rejections.sh

----

The core gate invokes its Agda entry points with the canonical theory profile
`--safe --without-K --cubical-compatible --exact-split --no-sized-types
--no-guardedness`. Core positive checks use `--no-libraries --double-check
--ignore-interfaces -W error`. Agda 2.6.4.3's

compares all 31 source modules, 24 rejection fixtures, and four integration
witnesses with exact path manifests; rejects additional `OPTIONS` pragmas, proof
escape hatches, and non-core imports; and verifies a generated negative
control: `--safe` must reject a planted postulate with Agda's expected
diagnostic and exit code.

== External pinned evidence, not local closure

Choreographic-types reports machine-checked K-CUT results for its explicitly
finite, binary-choice, plain-merge fragment, including K-CUT-LOSS, the
directional K-CUT-WARRANT bound, transport, and asynchronous variants. It also
reports `SoundWarrant` for warrants determined by that type-level frame.
Data-dependent warrants, recursion, full merge, and the wider asynchronous
forms remain open there. The previously recorded pinned E-6 receipt remains
external evidence; this repository does not generalise it into global warrant
soundness and does not count it as a locally rechecked theorem.

The current cross-repository status statements in
`docs/what-epistemic-is.adoc` are documentary pointers. They are not imports,
build dependencies, or independent proof legs for this repository.

== Explicit open obligations

* Complete epistemic logic beyond the implemented constructive frame fragment,
  including any desired classical converses for 5 and D.
* Soundness for data-dependent warrants; no global extraction rule is assumed.
* Re-proof the dependence result against residual-evidence-types' owning
  definitions if that external correspondence is to be claimed.
* Rational input or a proved common-denominator rescaling transport for the
  RapidNJ application; row insertion and cross-iteration bound reuse.
* Law-bearing instances where records currently expose laws as caller-supplied
  fields; no generic monad/comonad commitment.
* Full Conway-surreal semantics, full graded-loss/comonad semantics, external
  store/scheduler/attestation/runtime refinement, and physical guarantees.
* The theorem-level Rocq and Lean inventory, independent checks, and explicit
  proposition bridges needed for an independently reconciled result.
